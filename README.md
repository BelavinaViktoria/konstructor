# Конструктор ПВД и ИПР

Веб-приложение для двух процессов работы с людьми:

- **ПВД**: план ввода в должность нового сотрудника, цели на испытательный срок, пульс-опросы, сигналы о рисках, итоги испытательного срока;
- **ИПР**: индивидуальный план развития для кадрового резерва, от анкеты кандидата до финальной встречи;
- **аналитика**: срезы по адаптации и поиск проблемных зон.

Написано на Python (Flask, SQLAlchemy). Шаблоны страниц на HTML, база по умолчанию SQLite.

> **Статус: код ещё ни разу не запускался.** На компьютере, где он написан, нет Python. Проведена только статическая сверка маршрутов, шаблонов и парности тегов. Первый настоящий прогон тестов выполнит GitHub Actions после загрузки в репозиторий (или команда `pytest` на вашем компьютере). Ошибки при первом запуске возможны.

## Быстрый запуск

Нужен Python 3.10 или новее. Команды для Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
copy .env.example .env
flask --app wsgi seed-demo
python wsgi.py
```

Откройте <http://localhost:5000>. Команда `seed-demo` создаст вымышленные данные и напечатает пароль демо-пользователей:

| Почта | Роль |
|---|---|
| recruiter@example.com | Менеджер по подбору |
| manager@example.com | Руководитель |
| mentor@example.com | Наставник |
| newbie@example.com | Новичок |
| learning@example.com | Менеджер по обучению (админ-панель) |
| reservist@example.com | Резервист |
| top@example.com | Руководитель управления / зам. ГД |

Для рабочей базы вместо `seed-demo`:

```powershell
flask --app wsgi init-db
flask --app wsgi create-admin
```

Те же проверки запускаются на GitHub при каждой загрузке (`.github/workflows/ci.yml`).

## Что нельзя загружать в репозиторий

Репозиторий публичный. **Никогда не загружайте** файл `.env`, базу `instance/`, выгрузки с данными сотрудников, ТЗ и исходный прототип: в них внутренние сведения компании. `.gitignore` исключает эти файлы при работе через Git. При загрузке через браузер он не срабатывает, поэтому проверяйте список файлов глазами.

## Настройки

Все настройки лежат в `.env` (образец: `.env.example`). Без необязательных ключей приложение работает, соответствующая возможность просто выключена.

| Настройка | Зачем |
|---|---|
| `SECRET_KEY` | Обязательно на сервере: защита сессий |
| `APP_ENV` | `production` включает защищённые cookie и запрещает демо-данные |
| `DATABASE_URL` | База данных. На сервере лучше PostgreSQL |
| `SMTP_*` | Отправка писем. Без них уведомления видны только внутри приложения |
| `POTOK_API_KEY`, `FORMS_API_KEY` | Входящие интеграции |
| `ANTHROPIC_API_KEY` | ИИ на базе Claude. Без ключа работает разбор по правилам |

### Интеграции

Поток или промежуточный сервис присылает запрос, когда кандидат принял оффер. На рабочем столе появляется черновик ПВД. Повторный запрос с тем же `id` дубль не создаёт.

```bash
curl -X POST http://localhost:5000/api/potok/offer -H "X-API-Key: КЛЮЧ" -H "Content-Type: application/json" -d "{\"id\":\"123\",\"fio\":\"Иванов Иван Иванович\",\"position\":\"Кладовщик\",\"hire_date\":\"2026-12-01\",\"manager_email\":\"manager@example.com\"}"
```

Анкета кандидата в резерв приходит на `POST /api/forms/candidate` с полями `id`, `fio`, `position`, `department`, `upr`, `otd`, `site`, `manager_name`, `target`, `email`, `phone`, `experience`, `motive`, `initiator`.

Настоящий формат API Потока и Яндекс Форм здесь не проверялся: понадобится сопоставить поля или добавить промежуточный обработчик.

### Ежедневная проверка

Напоминания, просрочки, эскалации и сигналы зоны риска создаёт команда ниже. Запускайте её планировщиком раз в день. Повторный запуск дублей не создаёт.

```powershell
flask --app wsgi daily-tick
```

### Искусственный интеллект

- Без ключа разбор инструкции ищет строки обязанностей по правилам, а анализ отчётов всегда работает на правилах из прототипа.
- С ключом `ANTHROPIC_API_KEY` Claude готовит цели, задачи и навыки по инструкции и короткий вывод для руководства. При отказе модели включён серверный запасной вариант (`fallbacks`), при любой ошибке приложение возвращается к правилам.
- Во внешний сервис уходят только текст должностной инструкции и обезличенные сводные цифры. **Перед включением согласуйте это со службой безопасности.**
- Принцип сохранён: ИИ предлагает, решает человек. Ни одна цель не попадает в план без решения руководителя.

## Что перенесено из прототипа

| Блок | Статус |
|---|---|
| Роли, вход, разграничение доступа, журнал действий | Есть |
| Пребординг, письмо руководителю, напоминание о наставнике | Есть |
| Черновик из Потока | Есть (входящий запрос) |
| Рабочий стол, фильтры, счётчики, риск | Есть |
| Конструктор ПВД: блоки, задачи семейства, правка и удаление по одной | Есть, кнопками вместо перетаскивания |
| Цели 3–5, наставник, карта KPI, перенос в «Конструктор задач» | Есть |
| Должностная инструкция | .docx, .txt и вставка текста. PDF и сканы пока нет |
| План новичка, отчёты, «Нужна помощь», проверка руководителем | Есть, ссылкой вместо файлов |
| Пульс-опросы, встреча через месяц, итоги ИС, увольнение | Есть |
| Сигналы: тон ответов, план, выполнение, проверка, эскалации | Есть |
| Аналитика: срезы, фильтры, анализ, CSV, отчёт | Есть. Отчёт печатается из браузера |
| Кандидаты в резерв, конструктор и карточка ИПР, план резервиста, состав резерва | Есть |
| Админ-панель: пользователи, библиотека, письмо, реестры, журнал | Есть |

**Пока нет:** вложения к задачам и ИИ-инструкции по файлам, автоматический обмен с iSpring и Talent Q (данные вносятся вручную), выгрузки в Excel и PDF, редактор текстов всех писем и опросов, производственный календарь (учитываются только выходные), сброс пароля и вход через корпоративную учётную запись, перетаскивание блоков мышью.

## Перед запуском в работу

- Прогнать тесты и пройти основные сценарии вручную.
- Настроить HTTPS, резервные копии и `APP_ENV=production`.
- Подключить миграции базы (например Alembic): сейчас таблицы создаются командой `init-db`, и изменения схемы вручную не переносятся.
- Согласовать обработку персональных данных с юристами и службой безопасности (152-ФЗ).
- Выбрать лицензию: файла `LICENSE` нет, поэтому по умолчанию все права сохраняются за автором.
